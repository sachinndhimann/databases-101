# Chapter 8 — PostgreSQL vs MySQL & Production

This chapter consolidates the engine differences called out throughout the
repo into one reference, and covers production-facing topics that cut
across every earlier chapter: backups, monitoring, replication, and scaling.

## How to use this chapter

`docs/postgres-vs-mysql.md` is a reference — read it end to end once, then
come back to it whenever you're deciding which engine's behavior to expect.
`docs/production.md` and `workflows/` cover operational concerns.
